# Internet Research 原型 · 视觉预览

静态视觉预览，用于人工检查界面。GitHub Pages 站点：
**https://chloemmmmm.github.io/ir-checkout-preview/**

## 两个页面

| 页面 | 内容 |
|---|---|
| `index.html`（首页） | 结算页四条件 T0P0 / T1P0 / T0P1 / T1P1，可切换、可点「开始任务」、可加购 |
| `flow.html` | 完整 participant flow：入口 → 知情同意 → 基本信息 → 任务说明 → 理解检查 → 任务准备 → 结算页四条件 → K1–K5 与信心 |

## 四条件

| 条件 | 时间提示 | 优惠呈现 |
|---|---|---|
| T0P0 | 静态优惠截止时间 | 结果式 |
| T1P0 | 倒计时 | 结果式 |
| T0P1 | 静态优惠截止时间 | 过程式 |
| T1P1 | 倒计时 | 过程式 |

## 关于题库

`flow.html` 里**理解检查与 K1–K5 客观判断题的选项已遮盖（▓▓▓▓）**，
避免题库被公开检索、污染被试池。页面结构、题干、说明文字与信心滑尺保持原样。

## 注意

**这是视觉快照，不是可参与的实验。** 页面没有服务端：倒计时是浏览器本地计时，
加购后显示的金额与优惠卡来自服务端预先算好的结果快照。点击不写入任何数据，
也不会分配实验条件。不能用来收集数据。

真原型的价格、时间、随机化与结算裁定都在服务端，需要 Node + PostgreSQL 环境运行。
