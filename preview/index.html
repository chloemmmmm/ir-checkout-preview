研究者预览 · 选择条件

选择条件后进入结算页。进入后页面不再显示条件编码，也不含任何调试标签。

该版本为 interactive mock：无服务端、不连接数据库、不写入任何数据、不收集 participant_id； 全部状态仅存在于当前页面内存，刷新即重置（仅研究者选定的条件通过 sessionStorage 传递）。

仅供认知访谈与人工交互测试，不用于正式数据收集。 页面不含 consent / demographics / comprehension / C1–C3 / K1–K5 / questionnaire / debrief。
